# Annotate Zoom Image Viewer

**Version:** 1.1.0  
**License:** GPL-2.0+  

A high-performance, modern, block-based WordPress plugin for annotating single or collection images. Powered by OpenSeadragon (deep-zoom engine) and Annotorious (polygon and rectangle annotations) with full Gutenberg integration.

This document serves as a technical reference guide for developers looking to dissect, update, or reuse the plugin's architecture.

---

## 🏗️ Architecture Overview

The plugin utilizes a modern, decoupled architecture within WordPress:
- **Backend**: PHP 7.4+ with OOP structure, utilizing `WP_REST_Controller` for API endpoints, native WordPress metadata, and a custom annotation history table.
- **Admin Dashboard**: Top-level sidebar menu item located directly below **Settings** (`dashicons-tag` icon, position `81`).
- **Editor**: React-based Gutenberg blocks (`@wordpress/blocks`, `@wordpress/element`, `@wordpress/components`) with custom Inspector Controls.
- **Frontend**: Vanilla JavaScript (`view.js`) mapping JSON-LD annotation data dynamically to DOM elements and SVG layers using CSS variables for high-performance styling.
- **Engines**: 
  - **OpenSeadragon**: Handles deep-zoom, panning, and high-res image tiling in the fullscreen modal stage.
  - **Annotorious (W3C Image Adapter)**: Handles drawing, editing, and mapping of SVG vectors (rectangles/polygons) and comment/tag widgets.

## 💾 Data Storage & Schema

The plugin persists data in three distinct WordPress database locations to ensure decoupling of configuration, structure, and content:

### 1. Global Plugin Settings (`wp_options`)
Configured via the **Annotate Zoom Image Viewer** admin menu page:
- `arwai_azi_viewer_editing_roles` *(array)*: Array of WP role slugs allowed to edit annotations (e.g. `['administrator', 'editor']`).
- `arwai_azi_viewer_osd_options` *(array)*: Deep-zoom viewer configurations (`minZoomLevel`, `maxZoomLevel`, `showNavigator`, `gestureSettingsMouse`, `animationTime`).
- `arwai_azi_viewer_card_styles` *(array)*: Comprehensive array of global CSS variables for default badge styling, card borders, pill backgrounds, typography, and hover states.
- `arwai_azi_viewer_tag_colors` *(array)*: Array of objects mapping specific tag strings to styling hex codes (`tag`, `fill_color`, `border_color`, `badge_bg`, etc.).

### 2. Block Structure & Image Routing (`wp_postmeta` on Post/Page ID)
- `_arwai_azi_viewer_image_ids` *(json array)*: An array of Attachment IDs selected in the Gutenberg Viewer block. Used as a fallback if block attributes fail to parse.
- Serialized block attributes in `post_content` (e.g. `<!-- wp:arwai/azi-viewer {"imageIds":[12,14],"hideFilmstripMobile":true} -->`).

### 3. Annotation Data (`wp_postmeta` on Attachment ID)
- `_image_annotations_w3c` *(json array)*: Stores core annotation data conforming to the W3C Web Annotation Data Model (JSON-LD).
  - `id`: Unique UUID generated by Annotorious.
  - `type`: `Annotation`
  - `body`: Array of objects defining `purpose` (`commenting`, `replying`, `tagging`), `value`, `creator` object, and `created` timestamp.
  - `target`: Object containing `source` (image URL) and `selector` (SVG path or xywh fractional coordinates).
  - `db_id`: Custom integer appended by the PHP backend for sequential badging (1, 2, 3...).

## 📡 REST API Endpoints

Endpoints are registered under `image-annotator/v1` (with a legacy alias `arwai-image-annotator/v1` for backwards compatibility):

### `GET /wp-json/image-annotator/v1/annotations/attachment/{attachment_id}`
- **Purpose**: Fetches all W3C annotations for a specific image.
- **Auth**: Public (`__return_true`).

### `POST /wp-json/image-annotator/v1/annotations/attachment/{attachment_id}`
- **Purpose**: Creates or updates an annotation.
- **Auth**: Requires logged-in user with an allowed role (`arwai_azi_viewer_editing_roles`) and nonce verification (`X-WP-Nonce`).
- **Logic**: Merges updates by UUID, assigns a sequential `db_id`, appends user metadata to the `creator` object, and writes audit logs to `wp_image_annotation_history`.

### `DELETE /wp-json/image-annotator/v1/annotations/attachment/{attachment_id}/{annotation_id}`
- **Purpose**: Deletes an annotation by UUID.

### `GET /wp-json/image-annotator/v1/annotations/history/{annotation_id}`
- **Purpose**: Retrieves audit logs (history of edits) for a specific annotation.

## 🛠️ Gutenberg Blocks Technical Specs

### 1. Annotated Image Viewer (`arwai/azi-viewer`)
- **Location**: `src/viewer/`
- **Attributes**: `imageIds` (array), `width`, `height`, `backgroundColor`, `showFilmstrip`, `hideFilmstripMobile` (boolean, default: `true`), plus override styling attributes.
- **Stage Layout & Units**: Stage Height unit control supports `px`, `vh`, `rem`, `em` (omits `%` to prevent stage collapses). Tall images are constrained via `--stage-height-limit` CSS variables and `object-fit: contain` to eliminate image clipping.
- **Render Callback**: `ViewerBlock::render` (PHP) generates an inline HTML `style=""` injecting dynamic CSS Variables into the container wrapper.
- **Frontend Script**: `view.js` initializes carousel slide transitions, Annotorious SVG layers, and OpenSeadragon modal deep-zoom stage.

### 2. Annotation Cards List (`arwai/azi-viewer-annotation-list`)
- **Location**: `src/annotation-list/`
- **Attributes**: `targetViewerId` (string), `columns` (int), `overrideCardBg` (string), etc.
- **Multi-Viewer Isolation**: Dual-level targeting system (`data-target-viewer-id` explicit matching with an index-based 1-to-1 position fallback) ensuring multiple viewers on the same page independently toggle and refresh their respective cards list.

## 📱 Mobile Responsiveness & UI Controls

- **Dynamic Viewport Height (`100dvh`)**: OpenSeadragon fullscreen modal uses `100dvh` and safe-area insets (`env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`) so floating toolbars are never obscured by mobile browser URL bars, navigation bars, or camera notches.
- **100% Mobile Action Toolbar Pill**: Action toolbar pillbox (`Annotations`, `Enlarge`, `Info`) stretches to 100% width on mobile with stacked icon-over-text layout (`flex-direction: column`).
- **Single-Line Button Text (`white-space: nowrap`)**: Enforced no-wrap text rules prevent button labels from breaking onto a second line or expanding pill heights.
- **Automatic Greying Out of 0-Annotation Button**: When an image has 0 annotations, the "Annotations" toggle button automatically greys out (`opacity: 0.3`, `cursor: not-allowed`, `pointer-events: none`).
- **Synchronized Cards List Visibility**: Toggling the "Annotations" button in either the Simple Viewer or OSD Modal synchronously shows or hides the associated Annotation Cards List (`display: grid` / `display: none`).
- **Mobile Filmstrip Toggle**: Optional block setting to hide the filmstrip row on mobile viewports (`<= 768px`).

## 🎨 Frontend Styling Pipeline (CSS Variables)

The plugin uses a native CSS Custom Properties architecture for zero-lag, JS-free state transitions:

1. **Global Definitions**: Defined in `includes/Admin/SettingsPage.php`.
2. **PHP Injection**: `ViewerBlock::render` injects variables into the parent wrapper:
   ```html
   <div style="--nav-pill-bg: #ffffff; --nav-pill-color: #334155; --stage-height-limit: 500px;">
   ```
3. **CSS Consumption (`assets/css/public.css`)**: Native CSS pseudo-classes consume the variables:
   ```css
   .pill-nav-btn:hover {
       background: var(--nav-pill-hover-bg, rgba(255,255,255,0.1));
       transform: scale(var(--nav-pill-hover-scale, 1));
   }
   ```
4. **Annotorious Vector Formatter**: `view.js` uses `idBadgeAndColorFormatter` to inject inline CSS variables (`--tag-fill`, `--tag-border`) directly into SVG `<foreignObject>` badges and `<path>` vectors based on Tag rules.

## 📝 Recent Updates (v1.1.0)

### 1. Tabbed Admin Settings Interface
The admin settings page has been completely reorganized into a clean, tabbed interface using WordPress standard `.nav-tab-wrapper`. Settings are now logically grouped:
- **General & Permissions**: User role permissions and Tag/Term Custom Color Rules.
- **Annotated Viewer Block**: Simple Viewer & Stage Defaults, alongside OpenSeadragon (Deep-Zoom Modal) Engine Defaults.
- **Sequence Nav Pill**: Defaults for the sequence navigation pill block.
- **Action Pill Toolbar**: Defaults for the action toolbar block.
- **Annotation Cards List**: Defaults for the annotation cards grid block.

### 2. Standalone UI Blocks & Editor Previews
- The **Sequence Nav Pill** and **Action Pill Toolbar** have been decoupled from the main Viewer block into their own standalone Gutenberg blocks.
- Both blocks now support dynamic WYSIWYG editor previews and native block supports (color, spacing, border, typography).
- The default text color for these blocks has been updated to seamlessly inherit the active theme's text color (`currentColor`) when no custom color is specified.

### 3. Accessibility Enhancements
- **Screenreader Support**: Added descriptive `aria-label` attributes to the Previous/Next buttons, as well as the Annotations, Enlarge, and Info buttons.
- **Dynamic Aria States**: The Annotations toggle button now dynamically updates its `aria-pressed` state when annotations are shown or hidden.
- **Keyboard Navigation**: Implemented explicit `:focus-visible` CSS rules (`outline: 2px solid currentColor; outline-offset: 2px;`) to ensure all interactive pill buttons display a clear, high-contrast focus ring when navigating via the `Tab` key, regardless of the active theme's default styles.
